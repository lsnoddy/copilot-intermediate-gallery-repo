# Installation

## Requirements

- Node.js 18.18+ or 20+
- npm 9+

## Local setup

```bash
git clone https://github.com/lsnoddy/copilot-intermediate-gallery-repo.git
cd copilot-intermediate-gallery-repo
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- The repository currently uses `next/font/google` for the Geist font.
- In network-restricted environments, production builds can fail if Google Fonts cannot be resolved.
