# Documentation

This directory contains the repo-ready documentation set for the Next.js 15 photo gallery application.

## Structure

- [`api/openapi.yaml`](api/openapi.yaml) — OpenAPI 3.0 contract for the photo management API.
- [`api/authentication.md`](api/authentication.md) — Authentication and authorization expectations.
- [`api/error-handling.md`](api/error-handling.md) — Standard error format and client handling guidance.
- [`components/ui-components.md`](components/ui-components.md) — Usage notes for exported UI building blocks.
- [`adr/0001-use-nextjs-15-typescript.md`](adr/0001-use-nextjs-15-typescript.md) — ADR for the core framework choice.
- [`guides/installation.md`](guides/installation.md) — Local setup steps.
- [`guides/development.md`](guides/development.md) — Day-to-day development workflow.
- [`guides/deployment.md`](guides/deployment.md) — Deployment considerations for the app.
- [`guides/performance.md`](guides/performance.md) — Performance practices for the gallery experience.
- [`architecture/overview.md`](architecture/overview.md) — High-level system view.
- [`architecture/data-flow.md`](architecture/data-flow.md) — Request, component, and mock-data flow.
