# Contributing

Thanks for contributing to the photo gallery application.

## Setup

1. Fork or branch from the latest target branch.
2. Install dependencies with `npm install`.
3. Start the app with `npm run dev`.
4. Run `npm run lint` before submitting changes.

## Expectations

- Keep changes focused and easy to review.
- Preserve the existing Next.js App Router structure.
- Reuse shared UI components from `src/components/ui` where possible.
- Update documentation when behavior, architecture, or developer workflows change.

## Pull request guidance

- Describe the problem and the approach you took.
- Include screenshots or recordings for UI changes when helpful.
- Call out any known limitations, follow-up work, or environment-specific build issues.
- Keep pull requests small enough for targeted review.

## Documentation contributions

- Add longer-form technical content under `docs/`.
- Keep markdown concise, scannable, and linked from `docs/README.md` when relevant.
- Align component docs with currently exported components and real repository behavior.
